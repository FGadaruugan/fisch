# Fisch V1.0.0 — Major Update Plan

**Status:** In development  
**Release target:** V1.0.0  
**Feature branch:** `feature/v1.0.0-major-update`

## Release principles

- Keep the current Local/Account save formats readable; use an explicit migration and backup before changing save data.
- Keep the GitHub Pages `/fisch/` subpath working. Rebuild and commit `web/` and `resources.json` whenever source assets change.
- Keep core fishing playable when optional resource packs have not been downloaded. Every pack needs a manifest, version, byte size, integrity hash, dependency list, and retryable status.
- Respect mobile performance and `prefers-reduced-motion`; animation-heavy must not mean animation-blocking.
- Ship through small tested stages instead of replacing the whole game in one risky commit.

## Feature scope

### 1. Versioned systems
- **FSFS 3 (Fisch System):** catalogue/save/resource coordination, migration, inventory rules, system health and compatibility.
- **Fs 3:** fishing loop and Auto Catch v3, with explicit states, cancellation, busy-state protection, catch/reel feedback and regression tests.
- **ColorOS 3:** red-based visual identity, new CSS design tokens, responsive panels and layered animations.
- Shared version/build labels must agree across Lobby, Settings, About and resource manifest.

### 2. World and fish catalogue
- Current catalogue: 30 fish across 4 islands.
- Target catalogue: 100 fish total, adding 70.
- Add 3 islands (7 total). The final island is the endgame area and has 60 fish, including 8 `???` fish and 1 new `King` rarity fish.
- Define each fish with stable ID, island, rarity, weight range, price, XP, visuals and catch rules. Do not reuse IDs or silently change existing fish IDs.

### 3. Rods and luck/weight rules
- Keep existing rods and secret-rod acquisition intact during migration.
- Add 10 rods: 7 Rare and 3 Legendary.
- Add a King rod as a separate endgame concept only after its unlock and balance rules are explicit.
- Centralize rod effects in one rule function. Normal/Rare rods should not secretly alter fish weight; weight effects are restricted to Legendary-or-higher rules, with the King rod's Luck and weight effect handled explicitly.
- Show rarity, Luck, weight modifiers, unlock conditions and price in the rod details.

### 4. Backpack and player panels
- Backpack categories: Fish, Tools/Rods, Items, and smaller/utility items.
- Keep favorite/heart-protected fish excluded from Sell All.
- Add/refresh Top 30, Profile, Settings and About; keep mobile navigation and keyboard focus functional.

### 5. Downloadable resource packs
- Animation
- Fish, rods and items
- Map/world
- Critical systems
- Lobby
- Full / Additional / Core packs (current resource tiers retained and clarified)

Resource downloads must show progress, installed version, size, retry/cancel and clear errors. Validate the manifest and hashes; never execute downloaded text as code. Core gameplay must fall back safely if an optional pack is absent or corrupt.

## Implementation stages

1. **Foundation:** version constants, ColorOS 3 red theme and animation primitives; reduced-motion and mobile safeguards.
2. **Data migration:** schema/version migration tests; catalogue schema and explicit rarity/rod rules.
3. **World catalogue:** 3 islands and 70 new fish, with data validation and deterministic catalogue tests.
4. **Rods/inventory:** 10 new rods, rod categories, backpack categories and Sell All regression tests.
5. **Systems:** FSFS 3 / Fs 3 / Auto Catch v3 state machine and system diagnostics.
6. **Resource manager:** pack manifest, progress/error states, integrity verification, cache/version handling.
7. **UI polish:** Top 30, Profile, Settings, About, Lobby; transitions, catch reveal and island-entry animations.
8. **Release QA:** tests, build/package, mobile/reduced-motion review, save migration and GitHub Pages deploy.

## Release acceptance checklist

- [ ] Existing save is backed up before migration and remains recoverable.
- [ ] Exactly 100 unique fish exist; exactly 7 islands exist; the final island has 60 fish, including 8 `???` and 1 `King`.
- [ ] Ten new rods exist with 7 Rare and 3 Legendary classifications.
- [ ] King/Luck/weight rules are deterministic and tested.
- [ ] Auto Catch cannot double-cast or leave input held after cancellation.
- [ ] Sell All never sells favorited fish.
- [ ] All resource packs report accurate status and recover from failed downloads.
- [ ] ColorOS 3 uses red tokens and animations respect reduced-motion and small screens.
- [ ] `npm test`, `npm run check`, `npm run package` and Pages deployment pass.
