# Fisch 3D — эхний тоглож болох хувилбар
Огноо: 2026-10-14
Репо: https://github.com/FGadaruugan/fisch
Төлөв: хэрэгжүүлэхээс өмнөх загвар; хэрэглэгчийн review хүлээж байна.

## Зорилго, ойлгосон шаардлага
Хэрэглэгч GitHub дээр Fisch-ээс санаа авсан шинэ 3D тоглоом хүссэн.
Шинэ `FGadaruugan/fisch` репо хоосон байгааг шалгасан.

Эхний хувилбарыг browser дээр PC, Android утсаар тоглодог HTML/CSS/JavaScript тоглоом гэж санал болгож байна. Энэ платформ болон доорх эхний хувилбарын хүрээ нь одоогоор санал; Roblox Studio төсөл хүссэн бол хэрэгжүүлэхээс өмнө өөрчилнө.

Амжилтын шалгуур: тоглогч 3D арал дээр алхаж, ус руу саваагаа шидэж, загас барьж, барьсан загасаа зарж, мөнгөөрөө шинэ саваа авч чадна. Хуудсаа дахин ачаалахад ахиц нь тухайн browser дээрээ хадгалагдсан байна.

## Боломжит хандлагууд
1. **Санал болгож буй: browser + Three.js.** GitHub Pages дээр байршуулж, линкээр PC болон утаснаас тоглоно. Нэг тоглогчийн эхний хувилбарт тохиромжтой.
2. **Roblox Studio + Luau.** Roblox дотор тоглох, олон тоглогчийн ертөнц бүтээхэд тохиромжтой; GitHub нь код хадгалах үүрэгтэй болно. Browser дээр шууд тоглох хувилбараас өөр хүрээ.
3. **Godot + web export.** Engine-ийн scene/editor ашиглана. Эхний хувилбарт browser-ийн кодоос гадна engine төсөл, экспортын алхам шаардлагатай.

## Тоглоомын ертөнц, дүрслэл
Нэг low-poly арал, элсэн эрэг, мод, чулуу, жижиг байшин, загасчлах модон тавцан, нэг худалдаачинтай байна. Ус, тэнгэр, гэрэлтүүлэг, зөөлөн манан нь далайн орчныг гаргана. Нэг ертөнц дотор хөдөлдөг жинхэнэ 3D дүр, гуравдагч этгээдийн камер ашиглана.

Графикийн төсөв нь утсан дээр тоглоход чиглэнэ: энгийн геометр, материал дахин ашиглах, pixel ratio-г дээд хязгаартай байлгах, өндөр өртөгтэй post-processing хэрэглэхгүй. Загас барих үр дүнг UI болон жижиг 3D загасны дүрслэлээр харуулна.

## Загасчлах үндсэн цикл
1. Тавцан эсвэл эргийн тэмдэглэсэн хэсэгт очно.
2. “Шидэх” үйлдлийг дарж барихад хүч цэнэглэгдэж, суллахад шиднэ.
3. Хөвөгч усанд хүрээд санамсаргүй богино хугацаанд загас хүлээнэ.
4. Загас өгөөш авахад тодорхой хугацаанд “Татах” үйлдэл хийнэ. Хугацаа өнгөрвөл загас алдагдана.
5. Татах мини тоглоомд товчийг дарж/суллан удирдах барын байрлалыг загасны тэмдэгтэй давхцуулна. Давхцсан хугацаа ахиц нэмнэ; алдагдсан хугацаа ахиц бууруулна.
6. Амжилттай бол нэр, ховор байдал, жин, үнэ бүхий загас inventory-д нэг удаа нэмэгдэнэ.

Төлөвүүд: idle → charging → waiting → bite → reeling → caught/escaped → idle.
Хүлээлт 2–5 секунд, bite response window 1.8 секунд байна. Reeling ахиц 0.28-аас эхэлж, давхцсан үед секундэд 0.15 нэмэгдэж, давхцаагүй үед 0.10 буурна; 1 хүрвэл catch, 0 хүрвэл escape. 20 секундэд дуусаагүй reeling мөн escape болно. Нэгэн зэрэг хоёр catch үүсэхгүй. Cancel хийх, уснаас холдох, цэс нээх, tab солих үед холбогдох оролт болон хугацааг цэвэрхэн зогсооно. Tab далд үед тоглоомын цаг, мини тоглоом түр зогсоно.

## Ахиц, эдийн засаг
Найман төрлийн загас, common/uncommon/rare/legendary ховор байдлын ангилалтай байна. Жин болон загасны суурь үнэ нь зарах үнийг тодорхойлно.

Гурван саваа: Starter (үнэгүй, эхнээс тоноглосон, барын өргөн 0.24), River (150 coin, өргөн 0.30), Ocean (650 coin, өргөн 0.36). Ocean нь rare/legendary загасны сонголтын жинг 1.35-аар үржүүлж, бүх жингийн нийлбэрээр дахин normalize хийнэ. Загасны болон савааны тоон үзүүлэлт нэг data module-д төвлөрнө.

Худалдаачны ойролцоо interaction хийхэд inventory болон shop нээгдэнэ. Тоглогч загасаа нэг бүрчлэн эсвэл бүгдийг нь зарж болно. Мөнгө хүрэлцсэн үед шинэ саваа авна; авсан саваагаа тоноглож болно. Нэг загасыг давтан зарах, сөрөг мөнгө үүсгэх үйлдлийг state түвшинд хориглоно.

## PC болон утасны удирдлага
PC: WASD/сум — алхах; Space — үсрэх; mouse drag — камер; E — ойрын худалдаачинтай харилцах; F/action button — загасчлалын төлөвөөс хамаарах үйлдэл; Escape — цэс хаах/загасчлалыг цуцлах.

Утас: зүүн joystick — алхах; дэлгэцийн баруун хоосон хэсгээр чирэх — камер; баруун action товч — загасчлах; тусдаа jump/interaction товч. Бүх товч дор хаяж 44 CSS pixel хүрэх талбайтай. Pointer event ашиглаж, хуруу суллах болон pointercancel үед оролтыг цэвэрлэнэ.

Дүр ус руу нэвт алхахгүй; эхний хувилбарт арал, тавцангийн хилээр хөдөлгөөн хязгаарлагдана. Camera нь дүрийг дагаж, хэрэглэгч өнцөг болон зайг өөрчилж чадна.

## UI, хадгалалт, алдааны ажиллагаа
Монгол заавар, мөнгө, тоноглосон саваа, тухайн үйлдлийн товч заавар, inventory болон shop байна. Гол дэлгэцийн ихэнх хэсгийг 3D ертөнц эзэлнэ. Анхны тоглолтын богино заавар загас барих алхмуудыг үзүүлнэ.

Version бүхий localStorage save-д мөнгө, inventory, авсан саваа, тоноглосон саваа, нийт catch count хадгална. Snapshot-ийг schema, төрөл, зөвшөөрөгдсөн ID, тоон хязгаараар шалгана. Эвдэрсэн save эсвэл storage ашиглах боломжгүй үед тоглоом crash хийхгүй; хадгалалтын асуудлыг товч мэдээлээд ашиглаж болох session state үүсгэнэ.

WebGL ажиллахгүй бол хоосон дэлгэцийн оронд тайлбар болон дахин оролдох товч харуулна. Resize, orientation change, focus loss үед renderer, camera болон оролтыг шинэчилнэ.

## Кодын бүтэц, байршуулалт
Build шаардлагагүй ES module бүтэц:
- `index.html`, `css/game.css` — тоглоомын shell болон responsive UI.
- `js/main.js` — lifecycle, animation loop, module wiring.
- `js/world.js`, `js/player.js` — 3D орчин, collision, хөдөлгөөн, камер.
- `js/fishing.js`, `js/data.js` — fishing state machine болон data.
- `js/inventory.js`, `js/save.js`, `js/ui.js` — ахиц, хадгалалт, UI.
- `vendor/` — тодорхой хувилбартай Three.js ба лиценз.

Гаднын CDN-ээс runtime dependency татахгүй. Үндсэн кодыг fisch репод commit хийж, GitHub Pages дээр статик файлуудаар байршуулна. README нь удирдлага болон local HTTP server-ээр ажиллуулах аргыг тайлбарлана.

## Баталгаажуулалт
Fishing state transition, catch нэг удаа олгох, sell/upgrade тооцоо, эвдэрсэн save болон тоноглосон савааны validation-ийг meaningful unit checks-ээр шалгана.

Боломжтой browser орчинд эхлэх → алхах → загас барих → inventory → зарах → шинэ саваа авах → reload хийх бүрэн циклийг шалгана. Утасны viewport дээр joystick/action оролт, UI давхцал, orientation өөрчлөлтийг шалгана. Browser verification боломжгүй бол хэрэгжүүлэх үеийн тайланд тэр хязгаарлалтыг тодорхой бичнэ.

## Эхний хувилбарын хүрээ
Энэ хувилбар нэг тоглогч, нэг арал, нэг загасчлах бүс, найман загас, гурван саваатай. Завь, нэмэлт арлууд, online multiplayer, account болон server save нь дараагийн бие даасан өөрчлөлтөөр төлөвлөгдөнө.
